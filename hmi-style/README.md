## HMI Schematic Beautification Pack

This pack provides a consistent visual style and ready-to-use SVG assets to beautify device schematics (pipes, ducts, chimney, fan, dampers) without changing the existing layout.

### What's included
- Color and style tokens in `tokens.css`
- SVG assets in `svg/`
- A simple preview in `preview/index.html`

### How to use
1. Keep your current HMI layout intact.
2. Replace crude shapes with the provided SVGs while preserving position and size.
3. Tint colors via CSS variables or inline `fill`/`stroke` if needed.
4. For SCADA/HMI systems that embed bitmaps, export the SVGs to PNG at your target resolution.

### Style highlights
- Subtle gradients and soft shadows for depth
- Rounded joins/caps for smoother industrial look
- Calm industrial palette with semantic states (normal, warning, alarm)
